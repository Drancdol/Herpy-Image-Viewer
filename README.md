# Herpy Image Viewer

Herpy Image Archive 的移动端浏览应用

## 开发环境

- Node.js 22.11 或更高版本
- Android Studio 或 Xcode，以及对应的 React Native 开发环境

## 运行

安装 JavaScript 依赖：

```sh
npm install
```

启动 Metro：

```sh
npm start
```

在 Android 设备或模拟器上运行：

```sh
npm run android
```

在 iOS 模拟器上运行：

```sh
bundle install
bundle exec pod install --project-directory=ios
npm run ios
```

## 常用命令

```sh
npm run lint
npm test
```
